# Agent Instructions

## Project workflow

- Before work, read [product direction](docs/product.md), [milestones](docs/plan/INDEX.md), [status](docs/plan/STATUS.md), and the relevant technical contracts.
- Identify the current milestone and dependencies; select the smallest eligible task within the user's requested scope and state acceptance criteria.
- Honor the requested file and behavior boundaries. Never widen authorization to complete a milestone or treat future goals as current permissions.
- Distinguish proposed, implemented, and tested behavior. Make claims only from repository evidence; never infer completion from conversation memory.
- Validate only what can actually be validated, then update [status](docs/plan/STATUS.md) with evidence and unresolved blockers.
- Recommend the next eligible task. Do not autonomously skip gates or begin the next milestone.
